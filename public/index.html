      说明 / 接口文档
      

        
API：GET /api/sub?url=<订阅>&target=<格式>

        
支持格式：clash · clash-meta · singbox · v2ray · uri

        
鉴权：

        
    
          
  • 推荐：Authorization: Bearer <key> 请求头
    • 
          
  • 兼容：URL 查询参数 ?pass=<key>（密钥暴露在日志/历史中）
    • 
        

        
密钥配置（部署侧）：

        
    
          
  • KV 单条：wrangler kv key put --binding=AUTH_KV "key:<your-key>" "1"
    • 
          
  • KV 列表：wrangler kv key put --binding=AUTH_KV "keys" '["k1","k2"]'
    • 
          
  • 环境变量：wrangler secret put STATIC_KEYS 然后输入 k1,k2
    •
